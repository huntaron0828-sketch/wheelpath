# WheelPath · 공덕역·마포역 1km × 1km · 카카오맵 버전

## 실행 방법

- **카카오맵은 등록된 주소 https://huntaron0828-sketch.github.io 에서 열었을 때만 표시됩니다.** GitHub Pages에 올린 주소(예: https://huntaron0828-sketch.github.io/wheelpath/)로 여세요. `index.html`을 더블클릭해 열면 카카오맵 없이 보행로 지도만 보입니다.

- `index.html`을 더블클릭해 Chrome 또는 Edge에서 실행하세요. Node.js는 필요하지 않습니다.
- 출발지와 목적지를 검색창에 입력한 다음 **검색** 버튼을 누르고, 제시된 장소를 선택하세요.
- **내 조건으로 길 확인하기**를 누르면 이동거리/예상 시간과 지도가 열립니다.
- 모바일에서는 지도 화면 상단의 **설정** 버튼으로 검색 화면에 돌아옵니다.
- 가상 장애물은 **실험·조사 → 큰 지도에서 가상 장애물 설치**를 선택하여 지도에서 길을 터치한 다음 종류를 설정합니다.

## 변경 사항

- **장소 검색을 카카오 장소·주소 검색으로 바꿨습니다.** 두 글자 이상 입력하면 자동으로 찾고, 가게·건물 이름이 없으면 도로명·지번 주소로도 찾습니다. 결과는 1km 구역 안 장소만 보여주며, 반대편 지점(출발지/목적지)까지의 직선거리를 함께 표시합니다.
- **주변 시설 찾기:** 지하철역·병원·약국·공공기관·은행·편의점·카페 버튼을 누르면 마지막으로 누른 칸(출발지 또는 목적지)에 1km 구역 안 시설이 가까운 순으로 나옵니다.
- **최근 선택한 장소:** 빈 검색칸을 누르면 최근에 고른 장소 5곳이 나옵니다. 이 기록은 현재 브라우저에만 저장됩니다.

- **배경 지도를 카카오맵(2D)으로 바꿨습니다.** 지도를 열면 자동으로 연결되고, 그 위에 보행로·경로·횡단보도·가상 장애물을 겹쳐 그립니다. 연결에 실패하면 보행로 지도로 자동 전환됩니다. 카카오 JavaScript 키는 `index.html`의 `KAKAO_KEY`에 들어 있습니다.

- **지도에는 분석 구역(1km × 1km)만 보입니다.** 구역 밖은 단색으로 비워 두고, 구역 전체가 보이는 크기보다 더 축소하거나 구역 밖으로 끌어 이동할 수 없습니다. 온라인 배경 지도를 켜도 구역 밖은 가려집니다.
- **분석 범위를 공덕역·마포역 중심 1km × 1km로 줄였습니다.** 두 역의 중간 지점을 중심으로 동서·남북 각 500m 안에 완전히 들어오는 보행 링크만 남겼습니다 (링크 13,386 → 621개, 횡단보도 2,532 → 237개). 파일 크기는 약 2.9MB → 0.37MB입니다.

- 기존 지도를 통한 출발/도착점 선택 대신 **장소명 검색 및 결과 선택** 기능을 기본 조작 방식으로 적용했습니다.
- 공덕역, 마포역 및 보행로에서 계산한 지역 대표 위치는 인터넷 없이도 선택할 수 있습니다. 지역 대표 위치는 실제 건물 입구나 정확한 주소가 아닙니다.
- 검색 결과는 분석 구역 1km × 1km 경계 안으로 제한됩니다. 지도상의 장소 좌표는 인근 서울시 보행 네트워크 노드에 연결되어 길찾기에 사용됩니다. 이 연결은 실제 휠체어용 출입구를 확인한 것이 아닙니다.
- 초기 지도 렌더링과 온라인 MapLibre 지도 연결을 중단했습니다. 지도 화면을 열 때 처음 생성하고, 화면을 닫을 때 해제하여 모바일에서 상시 렌더링 부담을 낮춥니다.
- 기존 횡단보도 데이터, 개인별 휠체어 조건, 가상 장애물 추가, 사용자 측정 기록은 유지합니다.

## 네트워크 검색과 개인정보

카카오 장소 검색은 카카오 디벨로퍼스 앱의 무료 사용량 안에서 동작합니다. 사용자가 많아지면 사용량과 유료 설정을 확인하세요.
- 공개 서비스로 배포하려면 안정적인 전용 지오코딩 서비스 또는 별도의 자체 서버를 검토하세요.
- 검색어는 서비스로 전달됩니다. 집 주소 등 민감한 개인정보는 입력하지 않는 것이 좋습니다.
- 온라인 장소 검색과 실제 지도 배경은 인터넷이 필요합니다. 지역 내 기존 오프라인 목록과 보행로 시뮬레이션은 인터넷 없이도 실행할 수 있습니다.
- HTML을 직접 열었을 때 브라우저 보안 설정에 따라 카카오맵과 카카오 장소 검색이 작동하지 않습니다. GitHub Pages 주소로 열어 주세요.

## 중요한 제한

서울시 도보 네트워크는 경로의 연결성을 나타냅니다. 해당 보행로가 현재 실제 휠체어로 안전하게 지나갈 수 있음을 보장하지 않습니다.
보도 폭·턱 높이·경사 등이 확인되지 않은 구간은 미확인 상태이며, 가상 장애물은 실제 시설물이 아닙니다. 예상 시간은 설정값에 기반한 참고 계산입니다.
선택된 장소와 네트워크 노드 사이의 진입 경로는 별도 검증되지 않았습니다.
